# homepage0.5-project

My first website: a personal portfolio for Peace Alawode (NEWBOSS), built for Hack Club's Personal Site mission.

## Sections
- About me
- Projects (Kreatives Hub, EventSys, BookGuard, Student Login System)
- Skills
- Contact

## Built with
HTML, CSS and JavaScript, published with GitHub Pages. The JavaScript (`script.js`) adds a mobile menu, a project filter, an active nav link and a back-to-top button.
